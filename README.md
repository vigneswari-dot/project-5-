# Healthcare Data Analysis Project

## Project Overview

This project focuses on analyzing healthcare data to identify patient health risks based on medical parameters such as age, blood pressure, sugar level, cholesterol, and heart rate. The analysis helps understand health trends, categorize patients into risk groups, and visualize important patterns in the dataset.

## Objectives

* Generate and analyze healthcare patient data.
* Perform data cleaning and preprocessing.
* Identify missing values and handle them appropriately.
* Classify patients into risk categories.
* Group patients based on age ranges.
* Perform statistical analysis on health parameters.
* Visualize data using charts and graphs.
* Discover relationships between different medical attributes.

## Dataset Features

The dataset contains the following attributes:

* Patient ID
* Age
* Gender
* Blood Pressure
* Sugar Level
* Cholesterol
* Heart Rate
* Risk Category
* Age Group

## Methodology

1. Data Generation and Loading
2. Data Inspection and Validation
3. Missing Value Handling
4. Risk Classification
5. Age Group Categorization
6. Statistical Analysis
7. Correlation Analysis
8. Data Visualization

## Risk Classification

Patients are categorized into:

* High Risk
* Medium Risk
* Low Risk

The classification is based on blood pressure, sugar level, and cholesterol values.

## Data Analysis Performed

* Descriptive Statistics
* Gender-wise Blood Pressure Analysis
* Risk Level Distribution
* Correlation Analysis
* Age Group Analysis

## Visualizations Used

* Histogram for Blood Pressure Distribution
* Bar Chart for Risk Category Distribution
* Scatter Plot for Age vs Blood Pressure Analysis
* Heatmap for Correlation Analysis

The Healthcare Data Analysis project provides valuable insights into patient health metrics through statistical analysis and visualizations.
